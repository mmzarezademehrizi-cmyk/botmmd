# رباتِ تلگرامِ مستقل (بدونِ سایت و اپ)

فقط خودِ ربات؛ هیچ ارتباطی با سایت، اپ‌ها یا Firebase نداره.

## اجرا
```
bash install_bot.sh          # توکن و آیدیِ مالک رو می‌پرسه، venv می‌سازه، سرویسِ amirmmd-botonly رو روشن می‌کنه
```
دستیِ بدونِ systemd: `pip install -r requirements.txt` و بعد `python main.py`
(توکن: فایلِ `.bot_token` یا متغیرِ `BOT_TOKEN`؛ مالک: فایلِ `.owner_id` یا متغیرِ `OWNER_ID`).

## دیتا
دیتابیس `bot_data.db` کنارِ main.py ساخته می‌شه. اگه دیتایِ ربات‌ِ قبلی رو می‌خوای، فایلِ `bot_data.db` رو قبلِ اجرا همین‌جا بذار.

## چی حذف/بی‌اثر شده
- پوش و Firebase (features/notifications.py: توابعِ بی‌اثر)
- ذخیره‌یِ دائمیِ رسانه برایِ سایت (features/media_store.py: بی‌اثر)
- لینکِ ورودِ اپ از راهِ ربات (bot/bot_link.py: بی‌اثر) و کدِ اتصالِ مالک از سایت (`/linkowner` الان راهنمایِ `.owner_id` می‌ده)
- جاب‌هایِ مخصوصِ سایت/اپ: هشدارِ «نیاز به اقدام»، نگه‌داریِ شبانه‌یِ چتِ اپ، بک‌آپِ رسانه‌یِ چت
- مالک: با ورودِ یوزرنیم/پسوردِ سایت (`/ownerlogin`) کار نمی‌کنه؛ به‌جاش آیدیِ عددی توی `.owner_id`

## چی سرِ جاشه
مدیریتِ گروه/هشتگ/محتوا، کول‌داون و ضدِ فلود، ادمین/VIP، ناحیه‌ها و فرمانده‌ها، خروجی/ورودیِ اکسل،
بک‌آپِ روزانه (دیتابیس + کد) که برایِ مالک در تلگرام فرستاده می‌شه.
